# Crazyy-Game

A maze game idea, with multiplayer played on a console using mobile phones.

## Concept

Crazyy-Game is planned as a **maze game**. That is the core idea so far. The
maze design, rules and win conditions have not been decided yet.

## Multiplayer

The idea is to add **multiplayer**: the game runs on a console and players
join using their **mobile devices**, then start playing.

This is only a concept for now. It has not been built, and how players will
connect and control the game is still open.

## Status

🚧 **Early concept, no code yet.**

The repository only holds this README, which records the idea while the
project is being planned.

## Open question: graphics engine / application

The next step is choosing **which graphics application or engine to build the
game with**. That decision has not been made yet.

> **Food for thought:** these are suggestions, not decisions. They are common
> choices for maze and multiplayer games, listed to help with the choice. Any
> of them can be picked or replaced with something else.
>
> - **Unity** — widely used for 2D/3D games and mobile, lots of tutorials.
> - **Godot** — free and open source, lightweight, good for 2D and 3D.
> - **Unreal Engine** — strong 3D graphics, heavier to learn and run.
